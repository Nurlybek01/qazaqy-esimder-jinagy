# Қазақы есімдер жинағы

**«Әр есімнің өз мәні бар» — «У каждого имени есть свой смысл»**

«Қазақы есімдер жинағы» — проект двуязычного каталога казахских имён, который помогает узнавать их значения, происхождение и культурный контекст.

Главная идея — не просто собрать популярные имена, а постепенно создать удобный каталог с понятными объяснениями и проверяемыми источниками.

## Цели проекта

- Собрать каталог имён с казахским языковым и культурным контекстом.
- Добавить поиск по имени и фильтрацию по полу и алфавиту.
- Показывать значения, происхождение и варианты ласкового обращения.
- Указывать источники и отдельно отмечать спорные трактовки.
- Создать простой, современный интерфейс на казахском и русском языках.

## Дизайн

Проект использует спокойную природную палитру:

## Технологии

**Сейчас:** HTML, CSS и JavaScript.

**В планах:** React, JSON для хранения данных, GitHub и бесплатный хостинг.
