# Қазақы есімдер жинағы

**«Әр есімнің өз мәні бар» — «У каждого имени есть свой смысл»**

«Қазақы есімдер жинағы» — двуязычный каталог казахских имён.

Главная идея — не просто собрать популярные имена, а постепенно создать удобный каталог с понятными объяснениями и проверяемыми источниками.

## Цели проекта

- Собрать удобный каталог казахских имён.
- Поддерживать поиск и фильтрацию по полу и алфавиту.
- Показывать значение, происхождение и варианты имени.
- Добавлять проверяемые источники.
- Развивать интерфейс на казахском и русском языках.

## Дизайн

Используется спокойная природная палитра:

- Фон: `#F7F5EF`
- Основной зелёный: `#244331`
- Приглушённое золото: `#C6A56B`
- Цвет границ: `#DCD8CC`
